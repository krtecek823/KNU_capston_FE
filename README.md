# FE 3: 어드민 대시보드 (Analytics)

프로젝트의 성과 및 유저 행동 데이터를 실시간으로 모니터링하고 시각화하여 보여주는 관리자 전용 웹 어플리케이션입니다. 유저 개입 시나리오의 효과를 분석하고, 수집되는 데이터 신호의 정상 여부를 실시간으로 모니터링하는 데 목적이 있습니다.

## 🛠️ Tech Stack & Getting Started

이 프로젝트는 [Next.js](https://nextjs.org) (`create-next-app`)와 `next/font` (Geist Font)를 기반으로 구축되었습니다.

### Development Server 실행

로컬 환경에서 개발 서버를 구동하려면 아래 명령어 중 하나를 실행하세요.

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev

서버가 실행되면 브라우저에서 http://localhost:3000을 열어 결과를 확인할 수 있습니다. 메인 화면 및 라우팅 구조는 app/ 디렉토리를 기반으로 구성되어 있습니다.

🖥️ Core Features (어드민 페이지 4종 화면)
본 어드민 대시보드는 분석 및 관리를 위한 4가지 핵심 화면으로 구성되어 있습니다.

1. Live 화면
실시간 유저 행동 피드: 서비스 내에서 실시간으로 수집되는 유저들의 행동 신호(Signal)를 지연 없이 스트리밍 피드 형태로 시각화하여 모니터링합니다.

2. Scenarios 화면
시간대별 개입 횟수 차트: 유저 타겟팅 개입인 S1, S2 시나리오가 발동한 횟수를 시간대별 시계열 차트로 시각화하여, 관리자가 개입 추이를 직관적으로 파악할 수 있도록 돕습니다.

3. A/B Test 화면
성과 비교 통계 그래프: 특정 개입이 적용된 '개입군(실험군)'과 적용되지 않은 '통제군' 간의 전환율(Conversion Rate) 차이를 통계 그래프로 비교 분석합니다. 이를 통해 진행 중인 실험의 정량적 성과를 평가합니다.

4. Signals 화면
신호 수집 커버리지 모니터링: 시스템 내 정의된 총 16개의 핵심 데이터 신호가 누락 없이 정상적으로 수집되고 있는지 실시간 커버리지를 모니터링하고 상태를 추적합니다.
